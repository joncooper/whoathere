# Pass 3 Rubric: Testability, Verification Commands, And Handoff Quality

| Criterion | Weight | Passing standard |
| --- | ---: | --- |
| Commands exist | 20 | Plans provide concrete commands for local verification. |
| Tests map to owners | 20 | Phase plans align to GOAL-09 primary-owner matrix. |
| Implementation report | 20 | Report lists files changed, checks run, blockers, and resume prompt. |
| Handoff clarity | 20 | Next agent can continue without asking what to do next. |
| Scaffold testability | 20 | Phase 1 scaffold can run local tests or records blockers. |

Pass threshold: 90/100.
