# Pass 3 Rubric: Repeatable Verification And Discoverability

## Purpose

Evaluate whether the three-pass quality work is discoverable from the package root and final summary, and whether a future agent can rerun meaningful verification without reconstructing commands from chat history.

## Criteria

| Criterion | Weight | Passing standard |
| --- | ---: | --- |
| GOAL-10 discoverability | 25 | README and final summary list GOAL-10 and its purpose. |
| Pass artifacts complete | 25 | Three passes each have rubric, evaluation, improvement plan, execution notes, and verification. |
| Verification manifest | 25 | A central manifest lists commands, expected evidence, and what each command proves. |
| Final package consistency | 15 | Final summary and completion checklist reflect GOAL-10. |
| Mechanical checks | 10 | ASCII, stale-phrase, readiness-tier, and GOAL-09 handoff checks pass. |

## Pass Threshold

Minimum acceptable score: 95/100. Missing GOAL-10 discoverability or missing verification manifest is an automatic improvement item.
