## Outcome

The third teardown-stress gate proves escalation from TERM to KILL against an exact unprivileged
fixture rather than inferring resistance from a delayed host shutdown. After exec, the fixture
installs `SIG_IGN` for `SIGTERM` and sends a bounded readiness record that binds its PID. The
protected launcher verifies that PID, proc identity, and cgroup membership before starting a
guest-monotonic one-second deadline.

At the deadline the launcher proves the child remains live, delivers exactly one `SIGTERM`, and
proves the same process remains live for a complete 250 ms grace interval. It then delivers exactly
one `SIGKILL`, reaps that child as signal 9, and requires the strict protected event order
fork/exec/TERM/KILL/exit. Only afterward does it prove no descendant remains, close every sensor,
empty and remove the cgroup, and emit the canonical record. Rust and Swift independently require
the exact grace, signal, lineage, cleanup, health, heartbeat, and zero-drop fields and reject forged
or noncanonical variants.
